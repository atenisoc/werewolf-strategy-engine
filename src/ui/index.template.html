    ひとり人狼の遊び方
    
      
    ひとり人狼は、都道府県をモチーフにしたAIたちと一人で遊べる無料のブラウザ人狼ゲームです。登録・インストール不要で、スマホでもPCでも遊べます。
    
      
      
        
    1. 人数（5・7・9・13・15人）とモードを選んで始めます。「参加」は自分も村の一員として遊び、「観戦」はAI同士の対局を眺めます。
      2. 
        
    2. 昼は話し合い。怪しい人を疑う、信頼できる人をかばう、役職を名乗る（CO）などの発言を選びます。迷ったら「様子見」でも大丈夫です。
      3. 
        
    3. 投票で最も票を集めた人が処刑されます。5人・7人村は初日の処刑がなく、9人以上は初日から投票します。
      4. 
        
    4. 夜は役職ごとの行動です。占い師は1人を占い、狩人は1人を守り、人狼は1人を襲います。
      5. 
        
    5. 人狼が全員いなくなれば村の勝ち、人狼の数が残りの人数と同じかそれ以上になれば人狼の勝ちです。終わったら「AI思考を見る」で、AIがなぜその判断をしたかを振り返れます。
      6.

    役職の説明
    
      
      
        
    • 村人：特別な力はありません。発言と投票から人狼を探します。
      • 
        
    • 占い師：夜に1人を占い、人狼かどうか（黒か白か）が分かります。
      • 
        
    • 霊能者：処刑された人が人狼だったかどうかが分かります。
      • 
        
    • 狩人：夜に1人を人狼の襲撃から守ります。
      • 
        
    • 共有者：2人1組で、お互いが村人側だと分かっています。
      • 
        
    • 人狼：夜に1人を襲います。昼は村人のふりをします。
      • 
        
    • 狂人：人狼の味方をする人間です。占い師を騙って村を混乱させます。
      • 
        
    • 妖狐：どちらの陣営でもなく、最後まで生き残れば単独で勝ちます。人狼に襲われても死にませんが、占われると死にます。

    よくある質問
    
      
    
        
    人狼は一人で練習できますか？
    
        
    できます。相手はすべてAIなので、人を集めなくても好きな時間に1局遊べます。CO・投票・占いの流れを繰り返し練習するのに向いています。
    
        
    無料ですか？登録は必要ですか？
    
        
    無料で、登録もインストールも不要です。スマホ・PCのブラウザで開くだけで遊べます。
    
        
    AIはChatGPTなどの生成AIですか？
    
        
    いいえ。ルールに基づいて判断するAIで、LLMや外部のAIサービスは使っていません。判断はルール・性格・乱数を組み合わせて決めています。
    
        
    人狼のルールをまったく知らなくても遊べますか？
    
        
    遊べます。画面上部に「いま何をするところか」の説明が出ます。まずは5人村から始めるのがおすすめです。
    
        
    同じ対局をもう一度遊べますか？
    
        
    設定の「seed」に同じ値を入れて同じ操作をすると、同じ展開を再現できます。

    このゲームについて・v__VERSION__
    ひとり人狼 — 都道府県のAIと遊ぶ人狼ゲーム。登録不要、無料。相手はルールベースAIで、LLM・外部AI APIは使用しません。同じseedと同じ操作で対戦を再現できます。
